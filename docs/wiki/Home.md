# CLibUtilsQTR

Helpers for Skyrim plugins and general C++ code, from form lookup and logging to configuration and background tasks.

1. **[Install QTR](https://github.com/QTR-Modding/CLibUtilsQTR#installation-via-vcpkg)** - get the whole library into your CMake project.
2. **[Choose dependencies](https://github.com/QTR-Modding/CLibUtilsQTR/wiki/Getting-Started#choose-dependencies)** - optionally install only what your project needs.
3. **[Find a helper](https://github.com/QTR-Modding/CLibUtilsQTR/wiki/Getting-Started#find-a-helper)** - open the guide for the operation you want.
