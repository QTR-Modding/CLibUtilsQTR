# CLibUtilsQTR

A header-only C++23 utility library for Skyrim plugins and general C++ projects. There is no QTR DLL to build or distribute.

## Installation (via vcpkg)

[Install QTR with vcpkg](https://github.com/QTR-Modding/CLibUtilsQTR/wiki/Getting-Started#install-with-vcpkg). The guide covers the required files and CMake setup. The default installation includes every QTR header and all its external dependencies. You do not need to select modules.

Already using QTR? See [updating an existing installation](https://github.com/QTR-Modding/CLibUtilsQTR/wiki/Getting-Started#update-qtr).

## Optional dependencies

You can [select fewer dependencies](https://github.com/QTR-Modding/CLibUtilsQTR/wiki/Getting-Started#choose-dependencies), or [simplify your local port to always install everything](https://github.com/QTR-Modding/CLibUtilsQTR/wiki/Getting-Started#a-local-port-that-always-installs-everything). Both are optional; the supplied port works unchanged.
